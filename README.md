# 🎬 Zombie World - Movie Booking Website

Zombie World is a movie-themed website inspired by an action-horror concept.  
This project is built using HTML, CSS, and JavaScript.

## 🚀 Features
- Responsive Navigation Bar
- Hero Section with Movie Theme
- Buy Ticket Button
- Footer Section with Policies
- Payment Method Icons
- Deployed on Netlify

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Netlify (for deployment)

## 📱 Responsive Design
The website is designed to work on both desktop and mobile devices.
